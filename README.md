# दोGhut — Official Website

> **"Mai hu दोGhut ki chai. Ek Ghunt, Mood Set."**

Official responsive web application for **दोGhut** — Premium Chai & Rabdi Buns, with outlets in **Shaheen Bagh (Delhi)** and **Ahmedabad (Gujarat)**.

---

## 🫖 Features

- **Hero & Story**:
  - Illustrated storefront background with warm ambient lighting & lantern animation.
  - Floating logo, poetic tagline, and smooth scroll exploration.
- **What We Serve**:
  - Interactive 3D flip cards for the 5 signature menu items:
    1. Hyderabadi Dum Tea (₹25)
    2. Multigrain Rabdi Bun (₹80)
    3. Chocolate Rabdi Bun (₹80)
    4. Strawberry Rabdi Bun (₹80)
    5. Blueberry Rabdi Bun (₹80)
- **Catch Our Reels**:
  - Autoplaying, continuously looping Instagram video reels (`@2ghut_`).
- **Our Outlets**:
  - **Shaheen Bagh, Delhi** (Flagship: E-136/1 Azad Road, Near Shaheen Bagh Police Station, Okhla)
  - **Ahmedabad, Gujarat**
  - Integrated one-click Google Maps directions.
- **Our Story**:
  - Heartfelt storytelling with brand poetry and journey highlights.
- **Gallery**:
  - Real outlet ambiance photography, Embla carousel with autoplay, and interactive fullscreen lightbox modal.
- **Franchise Expansion**:
  - Responsive route connector (`Shaheen Bagh` ➔ `Ahmedabad` ➔ `Your City Next`) with franchise inquiry link.
- **Short Menu Board**:
  - Curated 5-item menu board with flavor notes, prices, and slogan.

---

## 🛠️ Tech Stack

- **Frontend**: React 18 + Vite 6
- **Styling**: Tailwind CSS 3
- **Animations**: Framer Motion
- **Carousels**: Embla Carousel React + Autoplay
- **Icons**: Lucide React

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build
```
